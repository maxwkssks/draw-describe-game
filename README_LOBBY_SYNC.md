# 그려봐! v5.4 대기실 동기화 수정

## 증상
같은 코드로 두 명이 참가했지만 한 화면에 1명, 다른 화면에 2명이 표시되거나 갱신이 느린 문제.

## 변경 내용
- `dd_state`(인원 목록) 조회를 먼저 처리하며, `dd_v5_presence_ping`(접속 확인)은 인원 조회 완료를 지연시키지 않도록 별도 실행
- 방/세션 교체 후 늦게 도착한 이전 응답 무시
- 서버 `revision`이 낮은 오래된 스냅샷이 최신 참가자 목록을 덮어쓰지 못하도록 제한
- 대기실에서 `↻ 인원 새로고침` 수동 갱신 버튼 제공
- 백그라운드 탭 복귀, 브라우저 포커스 복귀, 인터넷 재연결 시 갱신
- 팀 배정·사진선택·무제한·나가기·방장 이전·설명자 관전 기능 보존

## 설치
이번 버전은 **프런트엔드 코드만 변경**하므로 새 SQL을 실행하지 마세요.

1. ZIP 압축 해제 후 `draw-describe-web` **내부의 파일과 폴더**를 기존 GitHub Desktop 로컬 저장소 최상위에 덮어씁니다.
2. `Summary`: `v5.4 fix lobby player synchronization` → **Commit to main** → **Push origin**.
3. Vercel 최신 배포가 `Ready`가 되면 **두 브라우저를 각각 Ctrl+Shift+R로 새로고침**합니다.
4. 2인 대기실에서 양쪽 모두 `참가자 2/10`, 동일 닉네임, 준비 여부를 표시하는지 확인합니다.
5. 3번째 참가자 입장/퇴장 후 두 화면 갱신을 확인합니다. 지연 시 `↻ 인원 새로고침`을 눌러 수동 점검합니다.
