# 그려봐! v5.3 — 설명자 전용 그림 관전

- 개인전: 해당 라운드 설명자만 모든 그림 참가자의 서버 저장 스냅샷 열람
- 팀전: 레드/블루 설명자는 각자 자기 팀 그림만 열람
- 원본 사진: 기존의 설명자 제한 표시 유지
- 갱신: 브라우저가 약 2.8초 간격으로 RPC 호출; 그림은 참가자의 기존 자동 저장 시점(약 3초)까지만 반영됨
- 그림 참가자는 RPC 호출 시 서버에서 거부됨. 브라우저 UI 숨김만으로 권한을 처리하지 않음

## 설치
1. 먼저 운영 DB를 백업하고 `009_v5_blind_team_scoring.sql`까지 적용된 상태인지 확인
2. `supabase/010_v5_narrator_watch.sql`만 Supabase SQL Editor에서 실행
3. 이 프로젝트 파일을 GitHub 저장소 루트에 덮어쓰고 Commit/Push
4. Vercel Ready 확인 후 개인전 2인 및 팀전 4인으로 테스트

## 주의
- 진짜 실시간 공동 화면 공유가 아니라, 기존 자동 저장 결과를 폴링하여 보는 스냅샷 방식
- 타인의 그림이 보이지 않으면 저장이 아직 서버에 도착하지 않았는지, SQL 010 실행 여부를 확인
- 해당 라운드가 종료되면 RPC는 접근을 차단
- 실제 운영 Supabase에서 2~20명 부하/권한 테스트는 아직 진행되지 않음
